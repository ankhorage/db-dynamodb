# Ankhorage Coding Rules

Use a task branch, preserve unrelated work, and deliver coding work through a pull request. New production functions need concise Paradox comments. Test observable behavior at the owning boundary, export public symbols only through canonical entrypoints, add a Changeset for public release-impacting changes, and report the exact validation commands and failures.
